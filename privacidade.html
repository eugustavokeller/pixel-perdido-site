Política de privacidade

Última atualização: 15 de novembro de 2026

O aplicativo "Pixel Perdido" é uma ferramenta de uso exclusivo do dono do canal Pixel Perdido no YouTube. Ele não é oferecido ao público e não coleta dados de outras pessoas.

Quais dados o app acessa

Com a autorização do dono do canal (via login do Google), o app usa a YouTube Data API para: enviar vídeos ao próprio canal, definir título, descrição, tags e miniatura, e consultar se esses vídeos já foram publicados.

Como os dados são usados e guardados

O token de acesso fica armazenado apenas no servidor privado do dono do canal, com acesso restrito. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade. O app não acessa dados de espectadores, inscritos ou de outros canais.

Uso de dados das APIs do Google

O uso de informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado. O app também segue os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Os dados guardados podem ser apagados mediante pedido pelo e-mail de contato abaixo.
